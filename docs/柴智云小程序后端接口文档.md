# 柴智云小程序后端接口文档

供外部微信小程序调用

## 1. 基础信息

### 1.1 接口前缀

```text
http://47.113.113.212:8006
```

所有接口路径均在此前缀后拼接，例如：

```text
http://47.113.113.212:8006/api/ai/chatbot
```

当前后端配置为 `server.port=8006`、`server.address=0.0.0.0`

### 1.2 统一响应结构

后端统一返回 JSON：

```json
{
  "code": 200,
  "msg": "请求成功",
  "data": {}
}
```

常见字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | number | 业务状态码，成功通常为 `200` |
| `msg` | string | 响应提示 |
| `data` | any | 真实业务数据，失败时可能为 `null` |

常见失败示例：

```json
{
  "code": 401,
  "msg": "请先登录",
  "data": null
}
```

```json
{
  "code": 500,
  "msg": "请求错误",
  "data": null
}
```

### 1.3 鉴权方式

用户登录成功后，后端返回 `token`。小程序请求需要登录的接口时，在 Header 中携带：

```http
Authorization: Bearer <token>
```

权限分为三类：

| 类型 | 说明 |
| --- | --- |
| 公开接口 | 不需要 token，例如商品列表、藏品列表、AI 问答等 |
| 用户接口 | 需要普通用户 token，例如购物车、订单、兑换码、我的收藏、发帖 |
| 管理员接口 | 需要管理员账号 token，路径通常以 `/admin` 开头 |

### 1.4 Content-Type 约定

| 请求类型 | Content-Type | 适用场景 |
| --- | --- | --- |
| JSON | `application/json` | 登录、注册、购物车、订单、发帖、管理端新增/编辑 |
| 表单 | `application/x-www-form-urlencoded` | AI 问答、摘要、审核等 `@RequestParam` 接口 |
| 文件上传 | `multipart/form-data` | 图片鉴赏、社区图片上传、商品/藏品封面上传、GLB 上传 |

### 1.5 小程序请求示例

普通 JSON 请求：

```js
const BASE_URL = 'http://47.113.113.212:8006'

wx.request({
  url: `${BASE_URL}/collectibles/auth/login`,
  method: 'POST',
  header: {
    'Content-Type': 'application/json'
  },
  data: {
    username: 'test001',
    password: '123456'
  },
  success(res) {
    const body = res.data
    if (body.code === 200) {
      wx.setStorageSync('yc_token', body.data.token)
    } else {
      wx.showToast({ title: body.msg || '请求失败', icon: 'none' })
    }
  }
})
```

携带 token 请求：

```js
wx.request({
  url: `${BASE_URL}/shop/cart`,
  method: 'GET',
  header: {
    Authorization: `Bearer ${wx.getStorageSync('yc_token')}`
  },
  success(res) {
    console.log(res.data)
  }
})
```

表单请求：

```js
wx.request({
  url: `${BASE_URL}/api/ai/chatbot`,
  method: 'POST',
  header: {
    'Content-Type': 'application/x-www-form-urlencoded'
  },
  data: {
    question: '龙志雄是谁',
    context: '请基于检索到的柴烧非遗资料回答'
  },
  success(res) {
    console.log(res.data.data)
  }
})
```

上传文件：

```js
wx.uploadFile({
  url: `${BASE_URL}/api/ai/generate-image-description`,
  filePath: imagePath,
  name: 'file',
  success(res) {
    const body = JSON.parse(res.data)
    console.log(body)
  }
})
```

## 2. 用户认证接口

基础路径：`/collectibles/auth`

### 2.1 注册

```text
POST /collectibles/auth/register
```

完整地址：

```text
http://47.113.113.212:8006/collectibles/auth/register
```

权限：公开。

请求体：`application/json`

```json
{
  "username": "test001",
  "password": "123456",
  "displayName": "柴烧体验用户"
}
```

参数说明：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `username` | string | 是 | 用户名，长度 3-64 |
| `password` | string | 是 | 密码，至少 6 位 |
| `displayName` | string | 否 | 昵称，不传时通常使用用户名 |

成功响应：

```json
{
  "code": 200,
  "msg": "请求成功",
  "data": null
}
```

常见失败：用户名和密码不能为空、用户名长度需在 3-64 之间、密码长度不能小于 6 位、用户名已存在。

### 2.2 登录

```text
POST /collectibles/auth/login
```

权限：公开。

请求体：`application/json`

```json
{
  "username": "test001",
  "password": "123456"
}
```

成功响应：

```json
{
  "code": 200,
  "msg": "请求成功",
  "data": {
    "token": "JWT_TOKEN_STRING",
    "user": {
      "id": 1,
      "username": "test001",
      "displayName": "柴烧体验用户",
      "role": "user",
      "status": 1,
      "createdAt": "2026-06-18T10:00:00"
    }
  }
}
```

说明：管理员账号的 `role` 为 `admin`，普通用户通常为 `user`。

### 2.3 获取当前用户

```text
GET /collectibles/auth/me
```

权限：用户 token。

请求头：

```http
Authorization: Bearer <token>
```

成功响应 `data`：当前登录用户对象。

## 3. AI 智鉴与问答接口

基础路径：`/api/ai`

### 3.1 AI 图片辅助鉴赏

```text
POST /api/ai/generate-image-description
```

权限：公开。

请求类型：`multipart/form-data`

参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | 上传待鉴赏图片 |

成功响应：

```json
{
  "code": 200,
  "msg": "请求成功",
  "data": "{\"source\":\"api\",\"provider\":\"NVIDIA ...\",\"summary\":\"...\",\"confidence\":0.86,\"isCeramic\":true,\"isWoodFiredCeramic\":true,\"features\":[{\"label\":\"落灰层\",\"value\":\"...\",\"evidence\":\"...\"}],\"generatedAt\":\"2026-06-18T10:00:00Z\"}"
}
```

注意：该接口的 `data` 是字符串，字符串内部是 JSON。小程序端如果要读取 `summary/features`，需要二次 `JSON.parse(data)`。

示例：

```js
const reportText = res.data.data
const report = typeof reportText === 'string' ? JSON.parse(reportText) : reportText
```

报告字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `source` | string | `api` 或 `fallback` |
| `provider` | string | 模型来源或回退来源 |
| `summary` | string | 鉴赏摘要 |
| `confidence` | number | 置信度，0-1 |
| `isCeramic` | boolean | 是否识别为陶瓷主体 |
| `isWoodFiredCeramic` | boolean | 是否识别为柴烧陶瓷 |
| `features` | array | 特征列表，每项含 `label/value/evidence` |
| `generatedAt` | string | 生成时间 |

### 3.2 Base64 图片辅助鉴赏

权限：公开。

## 9. 小程序端调用建议

### 9.1 建议封装统一请求方法

```js
const BASE_URL = 'http://47.113.113.212:8006'

function request(options) {
  const token = wx.getStorageSync('yc_token')
  const header = Object.assign({}, options.header || {})
  if (token) {
    header.Authorization = `Bearer ${token}`
  }
  return new Promise((resolve, reject) => {
    wx.request({
      url: `${BASE_URL}${options.url}`,
      method: options.method || 'GET',
      data: options.data || {},
      header,
      success(res) {
        const body = res.data
        if (body && body.code === 200) {
          resolve(body.data)
        } else {
          const msg = body && body.msg ? body.msg : '请求失败'
          if (body && body.code === 401) {
            wx.removeStorageSync('yc_token')
          }
          reject(new Error(msg))
        }
      },
      fail: reject
    })
  })
}
```

### 9.2 表单接口单独指定 Content-Type

```js
request({
  url: '/api/ai/chatbot',
  method: 'POST',
  header: {
    'Content-Type': 'application/x-www-form-urlencoded'
  },
  data: {
    question: '曲江柴烧有什么特点？'
  }
})
```

### 9.3 文件上传需要单独封装

```js
function uploadFile(url, filePath, name = 'file') {
  const token = wx.getStorageSync('yc_token')
  return new Promise((resolve, reject) => {
    wx.uploadFile({
      url: `${BASE_URL}${url}`,
      filePath,
      name,
      header: token ? { Authorization: `Bearer ${token}` } : {},
      success(res) {
        try {
          const body = JSON.parse(res.data)
          if (body.code === 200) resolve(body.data)
          else reject(new Error(body.msg || '上传失败'))
        } catch (e) {
          reject(e)
        }
      },
      fail: reject
    })
  })
}
```

## 10. 状态码与业务注意事项

常见业务状态码：

| code | 说明 |
| --- | --- |
| `200` | 成功 |
| `400` | 请求参数错误 |
| `401` | 未登录、token 缺失或失效 |
| `403` | 无权限、账号禁用、非管理员 |
| `404` | 资源不存在 |
| `409` | 业务冲突，例如库存不足、重复兑换、编码重复 |
| `410` | 资源过期，例如兑换码过期 |
| `500` | 服务内部错误或第三方服务失败 |

小程序对接重点：

| 场景 | 建议 |
| --- | --- |
| 登录态失效 | 遇到 `401` 清空本地 token 并跳转登录 |
| AI 鉴赏接口 | `data` 是 JSON 字符串，需要二次解析 |
| AI 推荐/审核接口 | `data` 也是 JSON 字符串，需要二次解析 |
| 数字藏品领取 | 使用 `/collectibles/redeem`，不要直接调用 favorite 获取 |
| 图片地址 | 如果返回相对路径，前端拼接 `http://47.113.113.212:8006` 展示 |
| 文件上传 | 社区图片、商品封面、藏品封面最大 8MB；GLB 最大 100MB |
| 商城支付 | 当前是二维码/线下确认模式，用户标记已付款后由管理员审核 |
| 管理端接口 | 不建议暴露给普通小程序用户，必须使用管理员 token |
